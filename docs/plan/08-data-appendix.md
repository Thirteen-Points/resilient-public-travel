## 8. 技术选型与价格（截至 2026-09-21，落地前需再核）

| 层 | 结论 | 关键理由 |
|---|---|---|
| 地图库 | **Leaflet 1.9**（≈42 KB，插件最厚，新手友好） | 本场景节点数极少，不需要 WebGL |
| 底图 | **CARTO Positron（免费 key，500 万瓦片/月）→ OpenFreeMap → OSM 标准瓦片** | 降级链写进代码；OpenFreeMap 零 key 零限流但服务器在欧洲（HK 延迟偏高） |
| 路径引擎 | **Python + networkx 自建 headway 时序图**（非 OSRM/OTP） | 20–40 节点规模毫秒级出解；**代价函数可完全自定义**（轮椅/步速/换乘/票价），这正是差异化所在；OTP 需 GB 级内存且要自建港铁 GTFS，4 周来不及 |
| 步行接驳 | 先"直线距离 × 绕行系数 ÷ 步速"，有余力再离线算 OSRM 步行矩阵落盘 | 拿真实感但不背运维 |
| 后端 | FastAPI（单进程，图算法同进程） | 零额外服务 |
| 数据库 | SQLite 文件随仓库 | 数据量极小 |
| 仿真 | 纯 Python 离散时间步 + 队列分配（**不必真跑 1 万个 agent**） | 按 OD 比例分配即可，结果预计算落盘 |
| LLM 主选 | **DeepSeek `deepseek-v4-flash`**：$0.14 / 百万输入，$0.28 / 百万输出（缓存命中 $0.0028） | 中文强、支持 tool calling 与 JSON 输出、香港可直连 |
| LLM 备选 | **Qwen `qwen3.7-flash`**：$0.03 / $0.13（90 天 100 万 token 免费额度） | 全场最低价 |
| LLM 免费兜底 | **GLM `glm-4.5-flash`**：$0（永久免费，有速率限制） | 高频低价值调用（摘要、话术） |
| ⚠️ 避免 | **OpenAI / Gemini 官方 API** | 长期不支持香港地区，**现场大概率直接失败**；只在代码里留可选接口 |
| 部署（前端） | **Cloudflare Pages**（带宽不限、有 HK PoP、允许商用） | Vercel Hobby 禁商用；Netlify 免费额度易被暂停 |
| 部署（后端） | **Render Free**（750 h/月，**空闲 15 分钟休眠、冷启动 30–60 s**） | 必须配 cron 保活（T9.2） |
| 保活 | cron-job.org / UptimeRobot 每 10 分钟 ping `/api/health` | 演示前 10 分钟预热 |

**成本估算（整个项目）**：事件结构化每次 ≈2 k 输入 + 1 k 输出 token → 用 DeepSeek 约 **¥0.005/次**；按 500 次调用 ≈ **¥2.5**。预算上限设 **¥50**，超限自动切免费模型。
