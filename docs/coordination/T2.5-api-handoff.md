# T2.5 用户上报接口：A 接入说明

## 接口

- 方法与地址：`POST /api/signals`
- 请求头：`Content-Type: application/json`
- 成功状态：`202 Accepted`

请求示例：

```json
{
  "raw_text": "我在红磡站候车，列车停留较久，情况未确认。",
  "author_hint": "anonymous",
  "lang": "zh-HK"
}
```

- `raw_text`：必填，1–2000 字符。
- `author_hint`：可选，最多 100 字符；省略时后端使用 `anonymous`。
- `lang`：可选，支持 `zh-HK`（默认）或 `en`。
- 其他字段一律拒绝。ID、时间、来源和 provenance 由后端生成，前端不得传入。

成功响应只有 Signal ID：

```json
{
  "signal_id": "user-report-20260922T100000000000Z-a1b2c3d4e5f6"
}
```

常见错误：

- `422`：缺少正文、字段格式错误、正文过长或包含额外字段。
- `503`：Signal 收件箱暂时不可用。前端应提示稍后重试，不应显示提交成功。

## UI 必须表达的边界

用户提交的是**未经核实的原始报告**。成功响应只表示后端已经收妥，不表示交通事件已确认、已形成 Event 或已影响路线。表单旁和成功提示中应显示“未经核实，等待后续处理”的意思。

## 本地启动

在仓库根目录先安装依赖，再启动：

```powershell
python -m pip install -r backend/requirements.txt
python -m uvicorn backend.app.main:app --reload
```

默认地址为 `http://127.0.0.1:8000`，互动接口文档为 `http://127.0.0.1:8000/docs`。

PowerShell 手动请求：

```powershell
$body = @{
  raw_text = "我在红磡站候车，列车停留较久，情况未确认。"
  author_hint = "anonymous"
  lang = "zh-HK"
} | ConvertTo-Json

Invoke-RestMethod -Method Post `
  -Uri "http://127.0.0.1:8000/api/signals" `
  -ContentType "application/json" `
  -Body $body
```

## 当前接入限制

目前没有开放通配 CORS。如果前端和后端使用不同 origin，需要团队先确认 A 的开发地址和生产域名，再添加精确允许列表。

该接口当前只校验并保存 Signal，不会创建 Event、计算置信度、进入审核状态机或推送 SSE；这些属于后续任务。
