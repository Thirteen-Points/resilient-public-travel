# T4.1 模拟画像接入（A / C）

`GET /api/personas` 返回恰好五个完整 `UserProfile`：`demo_commuter`、`demo_student`、`demo_tourist`、`demo_elderly`、`demo_wheelchair`。均是模拟选择项，不对应真实个人，不存储姓名、账号或行程历史。A 可以用 `persona` 和 `note` 作选择器文案，并将所选对象作为 C 的 `POST /api/routes/query` 请求中的 `profile`；C 的路线引擎仍负责筛选、算路和打分。

每个画像的 `weights` 有八个评分维度且总和为 1；`hard_flags` 是约束，不得为了显示路线而被前端或预设覆盖。轮椅画像限定 `max_walk_m <= 400`，禁止楼梯、小巴及非低地台巴士。画像不是无障碍认证；路线仍须由 C 的可达性数据与硬过滤判定。
